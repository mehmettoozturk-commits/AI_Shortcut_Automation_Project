# AI Shortcut Automation Platform

AI ile doğal dilden mobil otomasyon/kestirme oluşturma platformu.

## Başlangıç

1. `MASTER_SPEC.md` dosyasını oku.
2. `CLAUDE.md` kurallarını uygula.
3. Önce Phase 0 feasibility çalışmasını yap.
4. Sonra UX prototype → AI Core → iOS MVP sırasıyla ilerle.

İlk hedef: iPhone üzerinde araçtan ayrılma → kullanıcıya soru → onay → desteklenen native/guided automation akışı.
